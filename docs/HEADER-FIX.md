# Install bar / app header spacing fix

31 October 2026. The PWA install bar occupied normal document flow while the desktop sidebar stayed fixed at viewport top zero. The bar covered the sidebar brand. Expanded install guidance was also absolutely positioned over the application header.

Changes are restricted to layout and regression coverage. At desktop widths (761px+), the sidebar now participates in the flex layout and becomes sticky at viewport top only on scroll. Its own viewport-height scroll region keeps long navigation reachable; main content no longer reserves a duplicate fixed-sidebar margin. Existing breakpoint widths and phone navigation remain. Expanded install guidance now occupies normal flow above the app instead of covering its controls.

Validation: production build and 4 focused Playwright tests passed (new header geometry test, 2 public-auth journeys and existing merchant-polish journey). Header test checks 1470/1024/800/430/390/360/320px widths, install guidance, offline banner, no horizontal overflow and desktop scroll stickiness. Ignored screenshots: artifacts/test-evidence/header-1470.png and header-390.png. No backend/schema/dependency changes or production data writes. Existing full regression baseline: 268 backend, 26 browser and 18 offline/frontend tests before this layout-only change; the new geometry case increases the complete browser suite to 27 when rerun.
